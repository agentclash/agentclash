## Usage errors

The CLI exits `64` for unknown top-level commands, missing required flags, unknown flags, incorrect argument counts, and flag values it cannot parse. Command groups such as `share` print their help and exit `0` for unknown subcommands.

With `--json` or an output format of `json` set by `--output` (`-o`) or saved configuration, the CLI writes a JSON usage error with `error.code` set to `invalid_argument` on stderr. Other output formats, including `yaml`, produce plain-text usage errors. Run `agentclash schema --json` for the exit code registry.
