## Usage errors

The CLI exits `64` for missing required flags, unknown flags or commands, incorrect argument counts, and flag values it cannot parse. With `--json`, `--output json`, or `--output yaml`, it writes a JSON error with `error.code` set to `invalid_argument` on stderr. Run `agentclash schema --json` for the exit code registry.
